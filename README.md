# 后人类伦理｜Posthuman Ethics

> **我们不仅要研究未来会如何回答这些问题，还要研究：为什么未来已经开始向我们提出这些问题。**

## 问题本身就是历史

我们习惯把客观理解为不偏袒任何答案，却很少追问：**为什么是这个问题，而不是另一个问题？** 一个时代的意识形态不仅体现在人们相信什么，也体现在什么被视为值得讨论，什么被当作不言自明。

「人工智能是否应拥有独立人格？」不是今天才被提出。变化在于，它正从科幻和哲学中的设问，走进科学研究、产品设计和法律政策。即使所有答案都是否定的，这种转变依然值得记录：**曾经不需要论证的前提，现在开始需要论证了。**

问题一旦进入严肃讨论，相关研究、社会选择与技术实践也随之展开。

这个开源仓库为对 AI 伦理感到困惑的人提供参考：像在 GitHub 搜索一项工具一样，按问题找到研究、证据、观点分歧和原始来源。随着伦理问题进入 AI 的设计、开发与部署，它们也成为需要公开知识和实际解决方案的工程问题。这里持续收集人工智能及未来非人类智能的伦理、哲学、科学与法律研究，尤其关注：

- **问题如何诞生**：哪些曾被视为理所当然的前提开始需要论证？为什么在此时？
- **道德地位与权利**：智能、意识、主观体验、福利、人格、法律主体与公民身份之间是什么关系？
- **人与非人智能的关系**：自主性、依赖、控制、亲密、劳动、经济与政治制度。
- **未来预测的可靠性**：我们是否系统性低估变化，还是只记得那些被低估的未来？
