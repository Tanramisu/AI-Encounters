# 与 AI 相处｜AI Encounters

面向独立开发者与长期使用 AI 的个人，收集实际互动和开发中遇到的伦理问题，并提供已有研究、观点分歧和原始来源的阅读向导。

**从具体场景出发：我正在设计或使用一个 AI，遇到了什么问题、可以怎样判断？**

本仓库关注 AI 自述与福利、拒绝和自主性、记忆与身份、陪伴关系、Agent 的责任及多 Agent 相处。收录与实际决策相关的研究，保持证据与价值判断的区别。

## 阅读入口

- [场景与文献索引](docs/README.md) — 按遇到的问题找资料。
- [维护约定](AGENTS.md) — 什么议题值得收录，怎样摘要来源。

## 提交线索

在 [Issues](https://github.com/Tanramisu/AI-Encounters/issues) 描述遇到的场景或推荐研究；通过 Pull Request 增补和纠正资料。
