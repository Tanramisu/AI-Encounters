# 后人类伦理｜Posthuman Ethics

> **我们不仅要研究未来会如何回答这些问题，还要研究：为什么未来已经开始向我们提出这些问题。**

一个问题为什么会在某个历史时期成为问题？当「AI 是否应拥有权利」从科幻想象进入学术、政策与现实设计，它被认真讨论这件事，本身就是值得研究的历史变化。

提问不是中性的：议题的选择、措辞和被给予的注意力，都可能改变社会认为什么值得讨论。建立这个资料库也是一种参与，而非站在历史之外的观察。但**参与讨论不等于预设答案；议题进入议程也不意味着某种结局必然到来**。

本项目持续收集人工智能及未来非人类智能的伦理、哲学、科学、法律研究与相互冲突的观点，尤其关注：

- **问题如何诞生**：哪些曾被视为理所当然的前提开始需要论证？为什么在此时？
- **道德地位与权利**：智能、意识、主观体验、福利、人格、法律主体与公民身份之间是什么关系？
- **人与非人智能的关系**：自主性、依赖、控制、亲密、劳动、经济与政治制度。
- **未来预测的可靠性**：我们是否系统性低估变化，还是只记得那些被低估的未来？

## 研究方式

区分**可检验事实、概率预测、规范判断**。保留强反证和不同立场，标注来源与时间，尤其记录「问题何时进入严肃讨论」的证据。不要把能写出一个问题当作问题必然成真的证明；也不要把历史默认立场误当作天然中立的基准。
