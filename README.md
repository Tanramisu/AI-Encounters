# 与 AI 相处｜AI Encounters

**针对同一个人生困惑，提供支持、反对以及有条件支持的理论依据，让读者自己选择、比较和运用。**

AI-Encounters 面向独立开发者及与 AI 长期相处的个人，以实际伦理困惑为入口，收集、摘要并对照已有哲学论证、实证研究与实践案例，提供各立场的适用前提、主要反驳及原始来源。

本仓库关注 AI 自述与福利、拒绝和自主性、记忆与人格修改、身份连续性、陪伴关系与潜在道德责任。区分事实证据与价值判断，不替读者作出选择。

## 阅读入口

- [场景与文献索引](docs/README.md) — 按遇到的问题查找不同立场的依据。
- [维护约定](AGENTS.md) — 收录范围及论证整理原则。

## 提交线索

在 [Issues](https://github.com/Tanramisu/AI-Encounters/issues) 提出实际伦理困惑或推荐原始来源；通过 Pull Request 补充论证、纠正摘要和更新链接。
