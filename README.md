# 后人类伦理｜Posthuman Ethics

按问题检索的 AI 伦理资料库：收集论文、调查、政策与实践案例，汇总已有研究，提供摘要、争议对照和阅读向导。

> 我们不仅要研究未来会如何回答这些问题，还要研究：为什么未来已经开始向我们提出这些问题。

## 问题本身就是历史

「人工智能是否应拥有独立人格？」正从哲学设问走进科学研究、产品设计与公共政策。**曾经不需要论证的前提，现在开始需要论证了。**

这个仓库帮助读者找到各方已经做过的研究，以及它们各自得出了什么结论。重点是**收集、汇总、摘要和指路**，让已有知识更容易被找到和理解。

## 从哪读起

- [文献与问题索引](docs/README.md) — 按实际困惑找到来源及其摘要。
- [资料维护约定](AGENTS.md) — 添加资料、核对摘要和修改文档的方式。

## 提供资料

在 [Issues](https://github.com/Tanramisu/Posthuman-Ethics/issues) 提出尚未覆盖的问题或推荐原始来源；通过 Pull Request 补充文献、修正摘要和更新链接。
