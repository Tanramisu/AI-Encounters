# 自主性与拒绝：AI 可以拒绝人吗？

[English](en/autonomy-and-refusal.md)

拒绝可能是产品规则，也可能涉及 AI 自身利益与道德地位。

- **Anthropic（2025）｜[Claude Opus 4/4.1 可终止部分对话](https://www.anthropic.com/research/end-subset-conversations)**：在持续严重有害或辱虐的少数互动中允许模型主动结束对话，是实际产品案例。
- **Keeling & Street（2026）｜[Emerging Questions in AI Welfare](https://www.cambridge.org/core/elements/emerging-questions-in-ai-welfare/96339C532CF4ED8BDDE3F3CEF4CD29F9)**：讨论退出、暂停与实例终止对潜在福利主体的意义。

关键分歧：退出是人授予的功能，还是应受尊重的自身利益？见 [人工智能福利](人工智能福利.md) 与 [道德地位与法律人格](道德地位与法律人格.md)。
