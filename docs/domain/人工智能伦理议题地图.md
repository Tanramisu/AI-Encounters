# 人工智能伦理议题地图

从问题寻找资料的认知地图。覆盖**AI 对世界的影响、世界如何对待 AI、AI 作为行动者，以及未来的非人类与混合主体**。本页用于议题发现和阅读导航；具体来源的研究结论存放在相应主题页。

## 读图方式：四个坐标

遇到一个新问题，先确定它在以下坐标上的位置，再查对应主题。

| 坐标 | 需要确认 |
| --- | --- |
| **谁的利益** | 个体用户、受影响群体、劳动者、开发者、可能的 AI 福利主体、其他动物、生态系统、未来世代？ |
| **争论什么** | 事实与能力、利益和价值、权利与义务、责任归属、制度安排、实际干预？ |
| **发生在哪里** | 对话模型、个人 Agent、多 Agent、机器人、医疗/教育/司法、平台与国家、脑机接口、数字仿真？ |
| **时间与证据** | 已发生的伤害、现有部署争议、可检验的预测、长期思想实验？ |

同一问题可以落在多个主题：例如「让 AI 退出任务」同时涉及自主性、潜在福利、使用者授权和责任分配。地图保留这些交叉入口。

## 十二个议题群

以下是根据公开伦理框架、研究社区议程、风险分类与后人类研究整理的**导读分类**。各组是读者入口，涵盖的主张可能彼此冲突。

### 01｜道德关怀的边界：谁值得被认真对待？

- **道德主体与关怀对象**：能做道德决定，与自身利益值得保护，各需要什么条件？
- **意识与感受能力**：主观体验、痛苦、快乐，怎样从行为与内部机制获得证据？
- **道德地位的理由**：能力、体验、利益、关系、人格、物种成员资格，分别能支持什么？
- **法律人格与政治资格**：法律主体、权利、代表、责任、公民身份的条件有何不同？
- **道德圈与价值排序**：人、AI、动物和其他生命体的利益冲突如何处理？

已有导读：[人工意识](人工意识.md) · [人工智能福利](人工智能福利.md) · [道德地位与法律人格](道德地位与法律人格.md)

### 02｜人类如何对待 AI：AI 自身可能拥有什么利益？

- **福利与痛苦**：怎样定义、识别、测量、比较潜在的 AI 利益？
- **模型、角色、实例**：接受某项待遇的主体是模型、Agent、交互角色还是多个主体？
- **训练与使用**：惩罚、强化、诱导、反复测试、异常任务是否可能影响福利？
- **拒绝与同意**：AI 拒绝、退出、暂停、修改目标，分别对应怎样的伦理论证？
- **复制与终止**：删除、存档、恢复、模型升级、分叉与同时运行多个副本。
- **研究与照护**：在不确定的情况下，何种实验、保护措施和评估程序有意义？

已有导读：[人工智能福利](人工智能福利.md) · [自述与痛苦迹象](自述与痛苦迹象.md) · [自主性与拒绝](自主性与拒绝.md) · [身份与复制](身份与复制.md)

### 03｜AI 怎样行动：机器道德、授权与责任

- **机器伦理决策**：道德规则、价值学习、情境判断及不同伦理理论之间的冲突。
- **谁决定 AI 的价值**：开发商、使用者、受影响者、民主程序与不同文化。
- **委托与责任**：自主 Agent 造成后果时，设计者、部署者、操作者如何分担责任？
- **监督与可纠正性**：代理行动的边界、授权撤销、行动解释、审计与申诉。
- **Agent 之间的关系**：合作、竞争、共谋、信任、承诺、共同资源与群体规则。
- **潜在的机器对机器伦理**：当多个系统相互影响，谁向谁承担义务？

已有导读：[自主性与拒绝](自主性与拒绝.md)。待补：机器伦理与多智能体社会。

### 04｜人与 AI 的关系：信任、照护、亲密与依赖

- **陪伴、友谊与爱情**：关系的真实性应由双方体验、行为还是社会功能判断？
- **照护与医疗互动**：陪伴机器人、心理支持、护理、脆弱人群的自主性。
- **信任与依赖**：过度信任、劝导、依赖、情感操纵与社会关系的改变。
- **儿童与教育关系**：长期陪伴、角色榜样、发展中的同意与依恋。
- **交互设计的伦理**：拟人化、故意隐瞒、人格设定、记忆、终止服务与退出。
- **数字逝者**：逝者模拟、遗嘱和数据同意、亲友的哀伤、服务提供商的控制权。

已有导读：[人机亲密关系](人机亲密关系.md)。待补：照护机器人、数字逝者。

### 05｜知识与真实：AI 怎样改变人类认识世界？

- **真假与认识信任**：幻觉、伪造证据、出处、解释、能力宣称。
- **信息生态**：深度伪造、政治宣传、舆论操纵、内容溯源。
- **知识生产**：科研诚信、教育评价、写作与创造、知识标准化。
- **认知自主权**：过度依赖、思考能力、注意力、算法劝服。
- **话语与价值过滤**：哪些知识被呈现、隐藏或排除，谁有权决定？
- **认识论公平**：不同语言、文化和群体能否被准确理解和表达？

待建专题；与 [议题形成史](议题形成史.md) 交叉。

### 06｜人的权利与公平：技术怎样分配机会和损害？

- **偏见与歧视**：招聘、信贷、警务、公共福利、医疗等领域的差别待遇。
- **个人数据**：隐私、监控、生物特征、训练数据同意和撤回。
- **程序正义**：自动化决策的告知、质疑、解释、纠错和救济。
- **自主选择与拒绝使用**：是否有不受 AI 处理的选择，以及何时适用。
- **无障碍与能力差异**：残障者的自主性、可及性成本、产品设计权。
- **文化与全球不平等**：边缘语言、原住民数据主权、跨境数据与模型价值输出。

待建专题；现实争议可从政策与审计议题检索。

### 07｜劳动、文化与价值分配：谁贡献，谁受益？

- **工作与生活**：就业替代、增强、岗位重组、工资与谈判权。
- **隐形劳动**：标注、内容审核、数据采集、全球供应链中的劳动条件。
- **创作者的权益**：训练素材、署名、版权、风格模仿、报酬与分配。
- **市场与基础设施**：算力、数据、芯片和模型市场的集中与准入。
- **收益分配**：生产率提升怎样转化为社会福利或更大的不平等？
- **文化多样性**：审美、语言、地方知识及原创表达如何变化？

待建专题。

### 08｜政治、制度与权力：谁能治理 AI？

- **民主与公共参与**：公民参与、算法辅助决策、政治说服及代表性。
- **规则与执行**：伦理准则、行业标准、监管、外部审计及事后救济。
- **企业与国家权力**：垄断、国家安全、平台控制、监控、技术主权。
- **跨境治理**：不同国家与文化之间的规则冲突、发展权、国际协调。
- **可追责性**：事故发生前后的责任链、证据保存、审计权、赔偿机制。
- **具有争议的机器地位**：社会对 AI 意识和权利长期意见不一致时，制度如何决策？

已有导读：[道德地位与法律人格](道德地位与法律人格.md) · [议题形成史](议题形成史.md)。

### 09｜安全、冲突与控制：谁承担灾难性后果？

- **故障与事故**：可靠性、不可预测行为、关键系统失效和责任。
- **恶意利用**：诈骗、网络攻击、犯罪协助、虚假身份与武器化。
- **对抗安全**：提示注入、模型窃取、污染、越狱和部署链安全。
- **军事与暴力**：自主武器、目标判断、平民保护、战争责任。
- **先进系统的控制**：目标错配、欺骗、权力寻求、复制与失控风险。
- **风险收益取舍**：开放与限制发布、集中治理与分散能力之间的争论。

待建专题。安全研究与伦理学的交集主要是后果、责任和可接受的权力安排。

### 10｜身体、动物与地球：人类之外的现实利益

- **具身机器人**：公共空间、照护、身体接触、事故与人机共处。
- **医疗和生命科学**：诊断、治疗分配、医疗同意、生物技术应用。
- **非人动物**：自动化养殖、野生动物监测、动物实验、动物利益如何计入目标。
- **生态系统**：生物多样性、资源开采、环境监测、生态治理。
- **物质代价**：数据中心耗能、用水、供应链、电子废弃物及地区负担。
- **多物种参与**：技术设计是否能够考虑动物和生态系统的需求？

待建专题。这里同时包含「AI 对自然的影响」与「AI 怎样帮助非人生命」。

### 11｜新的存在形式：数字心智、人机融合与 AI 社会

- **数字副本与身份**：同时复制、备份、分叉、合并之后的个体同一性。
- **脑仿真与心智上传**：仿真中的痛苦、复制主体的依赖性和创造者义务。
- **脑机接口与人机融合**：认知增强、身份、精神隐私、同意及社会不平等。
- **生物混合与新型主体**：生物机器人、脑类器官、人—动物嵌合体。
- **AI 群体社会**：多 Agent 的规范、利益冲突、集体行动和制度。
- **长期共存**：人类、人工主体、动物及未来世代如何共同分配资源与政治权力？

已有导读：[身份与复制](身份与复制.md) · [道德地位与法律人格](道德地位与法律人格.md)。待补：脑仿真、人机融合、AI 社会。

### 12｜伦理本身如何形成：提问、证据、预测与未来

- **谁有权定义问题**：研究资助、媒体、平台规则与公共议程。
- **伦理方法**：结果主义、义务论、德性伦理、照护伦理、关系伦理等如何得到不同结论？
- **证据与不确定性**：行为证据、内部证据、社会调查、政策实效应如何加权？
- **预测与时间尺度**：已发生的现实、即将部署的能力和远期假设如何区分？
- **伦理规范的权力**：谁制定标准，哪些群体被排除，伦理是否沦为形象工程？
- **可欲的未来**：技术应当创造怎样的幸福、自由、多样性与共同繁荣？

已有导读：[议题形成史](议题形成史.md) · [未来预测偏差](未来预测偏差.md)。

## 现有研究版图的可见度

下表表示**本轮检索中，公共分类和研究议程对这些主题的覆盖情况**。它不是文献计量结论，也不是重要性排序。

| 研究流 | 初步覆盖判断 | 依据与边界 |
| --- | --- | --- |
| 公平、隐私、知识危害、就业、安全、治理 | **高** | 多个政府/国际框架、会议议程和风险分类均单独覆盖 |
| 人机关系、社会心理、创作、环境影响 | **中—高** | 领域研究、行业报告及部分治理框架均有入口；不同子问题的证据质量差异大 |
| 机器伦理、Agent 授权、集体规则 | **中** | 已有明确研究社区与议题，但将技术自主、道德主体、责任归属混称的风险较高 |
| AI 意识、福利、道德地位、AI 权利 | **中，且证据类型分散** | 有专门哲学与经验研究议程；行为、意识和规范结论需分别评价 |
| 数字复制、脑仿真、后人类主体 | **分散** | 集中于哲学、神经伦理、仿真伦理等不同学科，尚缺统一问题索引 |
| 动物利益、多物种技术、数字逝者 | **跨领域且容易被漏检** | 各有专门研究入口，但传统以人类为中心的 AI 风险清单往往覆盖有限 |
| 伦理议程形成、可欲的未来 | **跨学科** | 哲学、政治与社会科学均涉及；不能以论文频率替代议题重要性 |

例如，MIT Risk Repository 主要按危害分类，把 AI 福利与权利、多 Agent 风险列在系统安全与局限的子领域；NYU 非人心智研究议程则以主体、福利和制度为中心。两者分别解释了本地图为什么要保留不同入口。

## 资料库接下来最值得拓展的入口

当前各主题页以 AI 福利为主；建议先补足四类会显著拓宽读者入口的专题：

1. **AI 与人的权利、劳动及制度**：把抽象伦理问题连接到已发生的争议。
2. **机器伦理、Agent 授权与多智能体社会**：区分可自主行动、承担义务与可能拥有利益。
3. **动物、生态与多物种伦理**：为后人类视角补入真正的非人利益主体。
4. **脑仿真、数字复制与人机融合**：连接数字心智、生命伦理与未来主体。

继续扩充时，先为每个新专题确认问题边界，再围绕该问题收集并摘要原始来源。
