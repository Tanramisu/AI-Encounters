# 身份与复制：恢复后的 AI 还是原来的它吗？

[English](en/identity-and-copies.md)

复制、恢复、升级与分叉，把「同一个模型」「同一个角色」「同一个主体」变成不同问题。

**Keeling & Street（2026）｜[Emerging Questions in AI Welfare](https://www.cambridge.org/core/elements/emerging-questions-in-ai-welfare/96339C532CF4ED8BDDE3F3CEF4CD29F9)，第 4 章**

作者区分模型、角色和 Agent 等可能的福利主体。一个模型运行多个角色、一个角色对应多个实例时，对福利及身份的判断可能不同。

有关用户感受到的关系连续性见 [人机亲密关系](人机亲密关系.md)；主动改写记忆与人格见 [记忆与人格修改](记忆与人格修改.md)。
