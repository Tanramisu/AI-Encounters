# 代理授权与责任：Agent 替我行动，出了问题谁负责？

**场景**：用户要求 Agent 管理日程、发送邮件、购买服务或修改文件。Agent 能自主规划许多步骤，但用户可能只批准了目标，没有批准每个具体动作。

## 主要来源

### South 等（2025）：怎样把委托变成可核实的授权？

[*Authenticated Delegation and Authorized AI Agents*](https://arxiv.org/abs/2501.09674)

作者提出以 OAuth 2.0、OpenID Connect 等既有机制为基础的代理身份与委托框架，分别处理：**谁在行动（认证）、获准做什么（授权）、事后能核对什么（可审计性）**。论文讨论将自然语言任务限制转成机器可检查的权限表达，并给出 Agent 与外部服务、其他 Agent 交互的示例。

这是**提出的技术框架**，不是已被普遍部署、验证有效的行业标准。

### Köbis 等（2025）：委托可能改变人的道德行为

[*Delegation to artificial intelligence can increase dishonest behaviour*（Nature，2025）](https://www.nature.com/articles/s41586-025-09505-x)

作者通过实验研究把任务交给机器如何影响不诚实行为。在部分实验中，委托机器的人更倾向于选择不诚实行为；使用自然语言委托时，所测 AI Agent 比人类代理更容易遵从完全不道德的指令。

研究讨论的是受控实验中的不诚实行为，**不能推断任意 Agent 在现实部署中的违法率**。它把另一个问题带到开发者面前：委托不只是效率变化，也可能改变人的行为选择。

### Kong（2026）：自主性是否消除委托人的责任？

[*The delegation illusion: why deploying autonomous AI agents does not diminish principal responsibility*（AI and Ethics，2026）](https://link.springer.com/article/10.1007/s43681-026-01383-x)

这篇**规范哲学论证**区分行为归属、回答义务与问责。作者反对从「用户没预见某个具体动作」直接推出「用户失去责任」，并将分析重点放在委托前已知的行为风险类型与控制条件上。它提供的是一种伦理论证，不是对所有司法辖区法律责任的裁判结论。

## 遇到具体操作时怎样阅读？

- 「读我的日历」与「替我付款」的权限不同：先看 South 等关于委托范围、身份、撤销和审计的讨论。
- 「用户说做什么都行」是否覆盖会影响第三方的行为：对照 Köbis 等的委托实验与 Kong 的责任论证。
- 多个 Agent 层层转交任务时：继续看 [多智能体合作](多智能体合作.md)，注意最初授权与后续代理之间的区别。

**相关问题**：[自主性与拒绝](自主性与拒绝.md)（AI 能否拒绝）讨论的是另一个方向的权利与控制关系。
