# 多智能体合作：几个 Agent 能形成信任与共同规则吗？

**场景**：开发者让多个 Agent 互相分工、共享资料、商议方案，甚至使用共同资源。它们会不会合作、违反承诺，或者因各自目标不同而损害整体结果？

## 直接研究

### Piatti 等（NeurIPS 2024）：共享资源下的合作

[*Cooperate or Collapse: Emergence of Sustainable Cooperation in a Society of LLM Agents*](https://proceedings.neurips.cc/paper_files/paper/2024/hash/ca9567d8ef6b2ea2da0d7eed57b933ee-Abstract-Conference.html)

作者构建 GovSim，让一组 LLM Agent 在共同资源有限的模拟环境中，选择利用资源还是维持长期可持续性。研究发现，大多数被测系统未能形成可持续均衡；实验中不同 Agent 的沟通与对长期后果的推理方式会影响合作结果。

**证据性质：模拟实验。** 能说明特定模型与环境下的协调行为，并不能证明 Agent 形成了真实的人类式社会、主观意图或道德权利。

### LLM Agent 与人类合作的实验（National Science Review，2026）

[*LLM agents overcome the machine penalty when acting fairly but not when acting selfishly or altruistically*](https://academic.oup.com/nsr/article/13/9/nwag223/8656786)

这项预注册研究涉及 **1,152 名参与者**，比较人—人及人—Agent 的多轮社会困境互动，并在主要实验中明确告知参与者对方是否为 AI。研究发现，表现出公平而非单纯无条件合作或自利策略的 Agent，更能引发与人—人互动接近的合作。

这是**人—Agent 的特定经济博弈实验**，不是多个真实自主 Agent 持续共同生活的证据；研究重点在可观察的合作及信任判断。

### South 等（2025）：Agent 之间的委托边界

[*Authenticated Delegation and Authorized AI Agents*](https://arxiv.org/abs/2501.09674)，附录中的 Agent 相互认证示例。

作者提出让 Agent 与 Agent 交互时验证身份和上游委托凭据。适合查找「A Agent 委托 B Agent 执行时，B 该信任谁的权限」这一设计问题。该方案仍属于提出的架构。

## 读者可以如何区分问题？

- **协作效率**：任务有没有成功？适合用真实任务结果与失败记录回答。
- **合作规范**：是否遵守承诺、共同资源是否耗尽？GovSim 等实验提供可观察指标。
- **授权关系**：谁让谁做事，权限如何传递？见 [代理授权与责任](代理授权与责任.md)。
- **潜在道德关系**：Agent 之间的义务是否具有独立道德意义？这还需要有关福利、主体与道德地位的研究，不能由合作表现直接得出。
